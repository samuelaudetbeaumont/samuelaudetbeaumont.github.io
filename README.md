# Academic website

A lightweight, static academic website. No build tools or dependencies are needed.

## Preview
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a public GitHub repository, for example `yourusername.github.io`.
2. Upload `index.html` and the three PDFs to the repository root.
3. In repository **Settings → Pages**, select **Deploy from a branch** and choose the `main` branch and `/ (root)` folder.
4. The website will be accessible at `https://yourusername.github.io/` (for a repository named `yourusername.github.io`).

## Edit
Open `index.html` with a text editor. All content and CSS are in one file. Keep the PDF filenames unchanged unless you also update their links in the HTML.
